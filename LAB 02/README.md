# 💻 CSC-531 Data Structure and Algorithms – Lab 02

This lab focuses on understanding and implementing **Array Operations in C++**. Students will learn how to perform basic operations on arrays, including insertion, deletion, and searching. These operations help develop an understanding of array indexing, element shifting, and traversal using loops.

---

# ⭐ Task 1: Insertion in an Array

## 🔍 Overview

This program demonstrates how to insert a new element into an existing array at a specific position. It initializes an array with five elements, displays the original array, shifts the existing elements one position to the right, and inserts a new value at the specified index.

## 🎯 Objective

To understand the insertion operation in arrays and learn how to shift existing elements to make space for a new value.

## ✔️ Output

Displays the original array before insertion and the updated array after inserting the new element at the specified position.

## ✍️ Learning Outcomes

- Declare and initialize an integer array
- Understand array indexing and positions
- Shift existing elements towards the right
- Insert a new value at a specific index
- Update the array size after insertion

---

# ⭐ Task 2: Deletion from an Array

## 🔍 Overview

This program demonstrates how to delete an element from an existing array at a specific position. It initializes an array with six elements, displays the original array, shifts the remaining elements one position to the left, and decreases the array size after deletion.

## 🎯 Objective

To understand the deletion operation in arrays and learn how to remove an element by shifting the remaining elements towards the left.

## ✔️ Output

Displays the original array before deletion and the updated array after removing the element from the specified position.

## ✍️ Learning Outcomes

- Understand the deletion operation in arrays
- Identify elements using array indexes
- Shift elements towards the left after deletion
- Update the array size using a counter variable
- Display the updated array using a `for` loop

---

# ⭐ Task 3: Searching in an Array

## 🔍 Overview

This program demonstrates the basic searching operation in C++. It takes five integer values from the user, asks for a target number, and searches for that number using a `for` loop. It compares each array element with the target value. If the number is found, it displays its index; otherwise, it displays an error message.

## 🎯 Objective

To understand the searching operation in arrays and learn how to find a specific element using a simple linear search technique.

## ✔️ Output

Displays the index of the target number if it exists in the array. If the number is not found, it displays an error message.

## ✍️ Learning Outcomes

- Take array elements from the user
- Understand the concept of linear searching
- Compare array elements with a target value using `if`
- Use a flag variable to check whether an element is found
- Use `break` to stop searching after finding the target
- Display an error message if the target is not present

---

# 📊 Comparison: Array Operations

| Operation | Purpose | Main Technique |
|---|---|---|
| **Insertion** | Add a new element | Shift elements right |
| **Deletion** | Remove an existing element | Shift elements left |
| **Searching** | Find a specific element | Compare elements one by one |
