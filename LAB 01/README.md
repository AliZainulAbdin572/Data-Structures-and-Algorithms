# 💻 CSC-531 Data Structure and Algorithms – Lab 01

This lab focuses on understanding and implementing **Arrays in C++**. Students will learn how to declare an array, take input from the user, store multiple integer values, and display all array elements using loops.

---

# ⭐ Task 1: Input and Display an Array of 6 Numbers

## 🔍 Overview

This program demonstrates the basic use of arrays in C++. It declares an integer array of size 6, takes six numbers from the user using a `for` loop, stores them in the array, and displays all entered elements using another `for` loop.

## 🎯 Objective

To understand basic array declaration, user input, data storage, and displaying array elements using loops.

## ✔️ Output

Displays all six integer values entered by the user in the same order as they were stored in the array.

## ✍️ Learning Outcomes

- Declare and initialize an integer array in C++
- Take multiple inputs from the user using a `for` loop
- Store values in specific array indexes
- Access and display array elements using indexing
- Understand basic array traversal using loops
